# Eronov Dilshodbek

I run The Endurance Industrial Technologies in Tashkent. We build automation and software for factories and industrial plants. I've been doing this for 3 years.

Things I've built:

- Ocard Industrial Line - app for production lines. Scans product codes on the conveyor, aggregates boxes into pallets, sends reports to Telegram.
- Ocard Desktop - desktop app for product marking: stock, sales, e-invoices, aggregation.
- Endurance Aggregator - tool for working with the Asl Belgisi marking API.
- C-MIND - production planning for oil refineries using linear programming, plus RBI. Tested on real plant data.
- FIFO WMS - warehouse system, running in production.
- Hydrolife - Telegram mini app with a voice assistant in Uzbek.

Mostly Python and TypeScript.
